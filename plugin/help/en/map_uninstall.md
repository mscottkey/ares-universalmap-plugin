# map/uninstall

Deletes all maps, tokens, and terrain objects created by the Universal Map plugin.

This action is **permanent** and **cannot be undone**.

## Usage

To initiate the uninstall process:

@map/uninstall


You will be prompted with a confirmation message.

To confirm:

@map/uninstall/confirm


Only Ares administrators may use this command.

---

Once complete, remove the plugin directory and config files manually, and restart your game to fully uninstall the plugin.

See also: `help map`
